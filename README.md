# Molina Studio

Terminal Linux dan pemutar media dalam satu aplikasi Android. Gratis, bebas, dan tanpa iklan.

## Apa itu Molina?

Molina Studio menggabungkan dua hal yang biasanya terpisah: terminal Linux untuk bekerja dan pemutar media bergaya
home theater untuk menonton dan mendengarkan. Semuanya berjalan langsung di ponsel Android Anda, tanpa perlu root.

## Molina Terminal

- Terminal dengan lingkungan Debian Linux.
- Pasang alat seperti Python, Git, dan FFmpeg dari menu Paket.
- Editor kode bawaan dengan sorotan sintaks dan pratinjau HTML.
- Cadangan setelan, Recycle Bin, dan penjelajah berkas.

## Molina Cinema

- Pemutar video dan audio dengan tampilan home theater.
- Melanjutkan tontonan dari posisi terakhir dan mendukung dekoder perangkat keras.
- Playlist IPTV dan Mode TV untuk menjelajah berkas ala saluran TV.
- Unduh video atau audio dari tautan lewat menu Unduhan.

## Privasi

Molina tidak memakai iklan, pelacak, atau layanan analitik. Riwayat dan statistik tontonan tersimpan di perangkat
Anda. Koneksi internet hanya dipakai untuk hal yang Anda jalankan sendiri, seperti memutar atau mengunduh dari tautan
dan memperbarui paket Debian.

## Kebutuhan

Android 8.0 (Oreo) atau lebih baru, dengan prosesor 64-bit (arm64).
